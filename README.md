# Worldwide-Weather-2025-Analysis
Global weather analysis and temperature prediction using Python, ML, and Power BI
## Overview
This project analyzes global weather data for 2025 using Python, Machine Learning, and Power BI.
It explores temperature, precipitation, rainfall, and snowfall patterns across countries and continents,
and includes a temperature prediction application.

## Technologies
- Python (pandas, numpy, scikit-learn, matplotlib)
- Streamlit
- Power BI
- Git & GitHub
